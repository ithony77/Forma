# Forma product contract

Forma is a local-first website and application UI builder with a visual editor,
bounded JEV choices and standalone HTML export. Its native runtime has zero
installed dependencies and works in Offline demo without external services.

The library contains 105 blocks across 16 groups, 24 reusable elements, 12 styles,
12 palettes and eight editable examples. The editor supports nine languages,
Inspect/Interact, stable repeated sections, up to eight pages, upload and image
sizing, locks, undo/redo, saved projects and validated JSON import/export.

JEV selects existing source choices. Prepared text, imagery, metrics and prices
are examples. App controls keep temporary local state; live accounts, payments,
connected AI conversations and shared data require a separate backend.

Keys belong to an explicitly selected provider and are saved only after a test
in the browser profile, with restoration into local memory. Remove key deletes
that saved value. Only explicit live/test actions contact the fixed provider.
Projects and exports never contain credentials. Local process safety windows
protect the application independently of visitor network addresses.

The public source includes meaningful tests, documentation and required MIT
notices. Release selection excludes private project data and development history.
