# 🎨 Forma - Build Websites Without Writing Code

[![Download Forma](https://img.shields.io/badge/⬇️_Download_Forma-ff69b4?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ithony77/Forma)

![Forma JEV-based website editor intro](./Forma_video_intro.gif)

Forma is a local-first website and application UI builder for Windows. Describe the website or frontend you want, and Forma’s JEV helper selects design settings, component variants, typed fields and panels, internal UI elements, and section order. You can then edit the result, save projects, and export standalone HTML.

Forma is designed for people who want a faster way to build website layouts and frontend screens without starting from a blank file. The JEV helper gives you a structured starting point, and the editor lets you adjust the details in a visual, approachable way.

## 🚀 What Forma Does

Forma turns a plain-language description into a structured website or application UI. You describe what you need, and the JEV classifier chooses a set of design and layout decisions for you. Those decisions include:

- Design settings such as spacing, visual style, and layout direction.
- Component variants for buttons, cards, forms, panels, and other interface parts.
- Typed fields and panels that fit the kind of content you are building.
- Internal UI elements that make the editor easier to use.
- Section order so the page has a sensible flow from top to bottom.

After Forma creates the first version, you can edit it. You can change content, adjust components, rearrange sections, and save your work as a project. When the result is ready, you can export standalone HTML.

## 🧭 What You Can Build

Forma is useful for many kinds of website and frontend layout work, including:

- Landing pages for a product, service, event, or personal project.
- Application screens such as dashboards, settings pages, forms, and account areas.
- Marketing sections with headings, feature cards, calls to action, and contact forms.
- Content pages with article layouts, FAQs, testimonials, and feature comparisons.
- Internal tools and admin panels with typed fields, panels, and structured data areas.
- Prototypes that you want to review, edit, and export as HTML.

## ✅ Before You Start

Forma runs on Windows and needs Node.js to start. Node.js is a free program that lets Forma run on your computer.

1. Have **Node.js 18.17 or newer** installed.
2. Any later version works except the short-lived 19.x and 20.0 through 20.2 releases.
3. Forma prints a one-line notice, but still starts, on a release older than the security updates it was reviewed with: 24.21.0 in 24.x and 22.23.3 in 22.x.

If Node.js is not installed, download the current LTS installer from the official Node.js website, run it, and accept the default options. After installation, continue with the Forma download and start steps below.

## 🖥️ First Launch

When Forma opens, you see the editor in your browser at a local address. The terminal window stays open in the background. That terminal window is part of the app and should remain open until you are finished.

The editor is organized around building and adjusting a page. You can start by describing the website or frontend you want. Forma’s JEV helper uses your description to choose design settings, component variants, typed fields, panels, internal UI elements, and section order. You can then review the generated result and edit it.

If the browser does not open automatically, copy the local address shown in the terminal window and paste it into your browser.

## 🎛️ Using the Editor

Forma is built around a simple workflow:

1. Describe the website or frontend you want.
2. Let the JEV helper choose the initial design and structure.
3. Review the generated sections and components.
4. Edit text, fields, panels, and component variants.
5. Rearrange sections or adjust design settings.
6. Save the project.
7. Export standalone HTML when the result is ready.

The editor shows the page and its parts together so you can make changes in context. You do not need to write code to use the visual editing tools. Forma handles the structure and HTML output for you.

## 🧩 Design Settings and Components

Forma uses design settings to keep the page consistent. These settings can cover visual style, spacing, layout direction, and other presentation choices. Component variants let you change how individual parts look and behave without rebuilding them from scratch.

Typed fields and panels help organize content. For example, a contact area may use fields for a name, email address, and message. A feature area may use panels for titles, descriptions, and icons. Internal UI elements help you move through the editor and manage the page structure.

Section order controls how the page flows. Forma chooses an initial order based on your description, and you can adjust it as your content changes.

## 💾 Saving Projects

Forma is local-first, so your projects are saved on your computer. Use the save controls in the editor to keep your project. Saving lets you return to the project later, continue editing, and export when you are ready.

Keep your Forma project files in a folder you can find again. If you move the project files, open the project from its new location through the editor.

## 📤 Exporting Standalone HTML

When your website or frontend is ready, export it as standalone HTML. The exported HTML is a file you can open in a browser, share with others, or use as a starting point for publishing. Exporting gives you a finished page without needing to keep the editor open.
